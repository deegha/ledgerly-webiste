## Where to find it

**Settings → Roles** shows the permission matrix — every action down the side, the six roles
across the top, a check where a role is allowed.

![The Settings → Roles permission matrix: rows for each action, columns for OWNER, ACCOUNTANT, BOOKKEEPER, APPROVER, AUDITOR and VIEWER](/guide/settings/roles-and-permissions.jpg "Settings → Roles — the same matrix for every organization")

This screen is **read-only**. The six roles are built in; you don't define your own. You
_assign_ a role to each person on [Settings → Team](/guide/settings/team-members).

## The full explanation

Each role — what it can do, what it deliberately can't, and how they combine to keep duties
separated — is covered in **[Users, roles, and
permissions](/guide/getting-started/roles-and-permissions)** in the Getting Started chapter.
